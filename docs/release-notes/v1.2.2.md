New in this build: the landscape record screen fits when Display Zoom is set to Larger Text or the text size is turned up.

New since 1.2.1:
- In landscape, when the full column doesn't fit, a compact one takes its place: the Show name moves to the header (tap it for the Show sheet), the note shortens to one line, and the Marker button shows its count as a badge. Record stays the same size and in the same place.
- Shows, Names and Gain are now buttons with a symbol over the word, each big enough to tap.

What to try, the riskiest first (checked only by tests and CI builds, never on a device or in the Simulator):
1. Set Display Zoom to Larger Text (Settings › Display & Brightness › Display Zoom) or turn up Text Size, then turn the iPhone sideways on the record screen. Can you see the status strip, the gear, Marker and Record, with nothing cut off?
2. With the usual text size, turn the iPhone sideways. Do you see the full column with the Show name, or the compact one? Either works; tell the developer which, and the iPhone model.
3. In the compact column, tap the Show name in the header. Does the Show sheet open? During a Take it should do nothing.
4. Record a short Take in landscape, drop a Marker and stop. Does the Marker count go up on the badge?
5. In portrait, tap Shows, Names and Gain. Do they open as before?
