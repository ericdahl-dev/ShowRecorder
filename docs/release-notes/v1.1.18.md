New in this build: this is the 1.1 build going to the App Store, and auto-gain is now part of it on X Air mixers. Free records every USB Channel; Pro adds names and colors from the mixer, the second Copy on a Drive, unlimited Markers, auto-gain and clip protection. The 14-day Trial includes everything.

New since 1.1.17:
- Auto-gain is in the App Store build too, with Pro, on an X Air mixer. On an X32 or M32 it stays in TestFlight builds only: the App Store build says it can't set that mixer's gain.
- Renaming or re-patching a channel on the Mixer during a Take is tracked in a new, simpler way. The change is logged and marked as before.
- The record screen's alerts and chips are worked out in a new way. Nothing should look different.
- The Trial now ends by the newest date the App Store has signed, not only by this iPhone's clock, once the iPhone has been online.
- The Reaper project has a marker where a channel was renamed on the Mixer during a Take, for example "USB 3: Vox → Lead Vox".

What to try, the riskiest first (all four were checked only by tests; auto-gain, Mixer names and the Reaper project need Pro or the Trial):
1. On an XR18 with Mixer Link up, run auto-gain. Does it still set each channel's preamp, keep the mix where it was, and put everything back with Undo? (The X32 refusal shows only in the App Store build, so a TestFlight build still runs auto-gain on an X32.)
2. During a Take, rename a channel on the Mixer, then re-patch a USB output to another channel. Does the app warn you about the re-patch and mark both moments, with the Stems named as in 1.1.17? After Stop, open the Reaper project: is there a marker at the rename?
3. Go through the record screen's alerts: start a Take without a Drive, plug one in, pull it out, swipe an alert away. Does each alert and chip show, fade and come back as it did in 1.1.17?
4. With the Trial running and the iPhone online, does the Trial still show the right number of days left?
