New: the Take you're recording now shows in the Dynamic Island and on the Lock Screen, so you can see it's still running without opening the app. It shows the Take, the Show, the time recorded and the number of Markers.

What to try:

1. Record a Take, then lock the phone. Does the Lock Screen show the Take, the Show, a running time and the Marker count?
2. Unlock and go to the Home Screen or another app. Does the Dynamic Island show a red dot and the time? Touch and hold it: does it open up with the Take, the Show and the Markers?
3. Go back to ShowRecorder and add a Marker. Does the count go up in the Dynamic Island?
4. Tap the Dynamic Island or the Lock Screen view. Does it open ShowRecorder on the record screen?
5. Stop the Take. Does the Dynamic Island and the Lock Screen view go away at once?

If you've turned off Live Activities for ShowRecorder (Settings > ShowRecorder), nothing appears, and recording works as before.
