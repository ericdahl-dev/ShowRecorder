New in this build: auto-gain lands on the Mixer's own gain steps and leaves channels fed from USB alone, the Auto-gain sheet fits the iPhone screen, and a Take that missed its Drive ends in an orange summary.

New since 1.2.5:
- Auto-gain moves each preamp in the XR18's 0.5 dB steps and never past what the fader and sends can make up, so the mix stays where it was. A request between steps rounds down: +7.3 dB moves +7.0 dB.
- A channel fed from USB on the XR18 (its input switched to USB) gets no gain move. The Auto-gain sheet says "Channel N is fed from USB on the Mixer, so its preamp can't change what's recorded."
- With two Mixers of the same family on the network (two XR18s, say), auto-gain stays off, so it can't move the wrong Mixer.
- The Auto-gain sheet fits the iPhone screen: the Done button is fully visible, and each row's Undo and Auto-gain buttons move under the text when there isn't room.
- With a Drive folder set but the Drive missing, a Take ends with an orange "Saved on this iPhone only: the Drive was missing" ("this iPad" or "this Mac" there), not a green check.
- Deleting a Show, a Take or a channel file no longer stalls the app on a slow Drive. The button reads "Deleting..." until it's done.

What to try, the riskiest first (checked only by tests and CI builds, never on a device or in the Simulator):
1. With the XR18 linked, run auto-gain on channels 1 and 2 (a linked pair). Does each gain land on a whole or half dB, and does the mix sound the same afterward? Then Undo all.
2. Switch one channel's input to USB in X AIR Edit and run auto-gain on it. Does the sheet say it's fed from USB, with no gain change on the Mixer? Switch it back and run it again: does the gain move now?
3. Open the Auto-gain sheet after a result, then again at the largest text size (Settings > Accessibility > Display & Text Size > Larger Text). Is Done fully visible, and does nothing run off the right edge?
4. Set a Drive folder, unplug the Drive, record a short Take and Stop. Is the summary orange, with the line above?
5. Delete a Take, then a Show, with the Drive plugged in. Does the button read "Deleting..." and the app stay responsive? Try once with the Drive pulled partway through.
