# Behringer XR12 / XR16 and Midas MR12: multitrack recording facts

**Bottom line: no multichannel USB audio.** These mixers have no USB-B audio interface. They only record **stereo** to a USB flash drive.

ShowRecorder cannot multitrack these mixers over USB. An honest guide should say so and point to the XR18 or MR18.

Source labels: [B-x] = Behringer (maker). [S-x] = secondary.

## 1. USB audio to a computer

- **None.** The manual says: "the X18 and XR18 feature an 18x18 USB audio/MIDI interface, and the **XR12 and XR16 allow 2-track stereo recording**" [B-1].
- The XR16/XR12 spec lists "USB port: **Type A**" (a flash drive host), not a Type B audio interface [B-1].
- Processing includes "16 input channels, 1 stereo USB return channel" [B-1]. The "USB return" is playback from the flash drive.
- **MR12:** a retailer says "It does not include a multi-channel USB audio interface for DAW recording" and lists a Type-A USB port [S-1].

## 2. Driver status

Not applicable; there is no computer audio interface.

## 3. Recording without a computer

- **USB Type A flash drive:** "accepts a flash drive for file storage, stereo recordings and playback. The red LED next to it indicates file access. Do not remove the USB flash drive while it is lit!" [B-1].
- XR16 product page: "Plug a USB flash drive into the mixer to record the night in stereo" and "USB stereo recorder: record and play back stereo files on a USB flash drive" [B-2].
- XR12 product page: "a USB stereo recorder" [B-3].
- The block diagram shows "USB RECORDER: STEREO REC (VARIOUS SOURCES)" and "STEREO PLAY (specific 'USB' stereo input channel)" [B-1].
- **File format:** WAV bit depth, sample rate and maximum file size are not stated in the maker text found (unknown).
  - Converters are "24-bit @ 44.1 / 48 kHz" [B-1].
  - A retailer describes MR12 recordings as "uncompressed stereo WAV" [S-1] (secondary).
- **Channel count:** 2 (stereo) [B-1].

## 4. Recording settings

- Sample rate: 44.1 / 48 kHz for the mixer [B-1].
- The recorder source is selectable ("various sources"). The exact menu path and source list: unknown from maker text.

## 5. Routing

- The stereo recorder source is chosen in the app ("various sources" [B-1]); the menu path is unknown.
- Inputs and outputs use the same X AIR routing page as the XR18. On the XR16/XR12 the routing page has no USB multichannel sends [B-1 §6.13].

## 6. Tap points

- These are not relevant to multitrack.
- Analog gain and phantom sit before the channel, as on the XR18 [B-1].

## 7. Gotchas

- **The biggest gotcha: the XR12, XR16 and MR12 look like the XR18 but send no multichannel audio over USB.** You get only a 2-track stereo file on a flash drive.
- They have the same app, the same look and the same "X AIR" family name as the XR18. Users will expect USB multitrack and not get it.
- Workarounds outside USB: use analog direct or aux outs into a separate interface. That is a different product category, and the guide should not promise it.
