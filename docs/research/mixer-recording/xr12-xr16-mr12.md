# Behringer XR12 / XR16 and Midas MR12: multitrack recording facts

**Bottom line: no multichannel USB audio.** These mixers have no USB-B audio interface. They only record **stereo** to a USB flash drive.

ShowRecorder cannot multitrack these mixers over USB. An honest guide should say so and point to the XR18 or MR18.

Source labels: [B-x] = Behringer (maker). [M-x] = Midas (maker).

## 1. USB audio to a computer

- **None (XR12, XR16).** The manual says: "the X18 and XR18 feature an 18x18 USB audio/MIDI interface, and the **XR12 and XR16 allow 2-track stereo recording**" [B-1].
- The XR16/XR12 spec lists "USB port: **Type A**" (a flash drive host), not a Type B audio interface [B-1]. The XR12 and XR16 product pages also list a Type A port [B-2][B-3].
- Processing includes "16 input channels, 1 stereo USB return channel" [B-1]. The "USB return" is playback from the flash drive: the block diagram calls it "STEREO PLAY (SPECIFIC 'USB' STEREO INPUT CHANNEL)" [B-1].
- **MR12: none.** The Midas manual says: "the MR18 features an 18x18 USB audio/MIDI interface, and the **MR12 allows 2-track stereo recording**" [M-1]. Its MR12 rear panel: "USB port (type A) accepts a flash drive for stereo recordings and playback" [M-1]. The MR12 spec lists "USB port: Type A" [M-1].
  - Some retailer listings call the MR12 a 12-channel USB audio interface. That conflicts with both Midas sources. Don't repeat it.

## 3. Recording without a computer

- MR12: "Plug a USB flash drive into the type A port to record the show in stereo" [M-2]. The Midas manual has the same red-LED warning [M-1].
- **USB Type A flash drive:** "accepts a flash drive for file storage, stereo recordings and playback. The red LED next to it indicates file access. Do not remove the USB flash drive while it is lit!" [B-1].
- XR16 product page: "Plug a USB flash drive into the mixer to record the night in stereo" and "USB stereo recorder: record and play back stereo files on a USB flash drive" [B-2].
- XR12 product page: "USB stereo recorder: stereo WAV recording at 16-bit, 44.1 or 48.0 kHz" and "A USB flash drive records the show as stereo WAV files" [B-3].
- The block diagram shows "USB RECORDER: STEREO REC (VARIOUS SOURCES)" and "STEREO PLAY (specific 'USB' stereo input channel)" [B-1].
- **File format:**
  - XR12: stereo WAV, 16-bit, 44.1 or 48 kHz [B-3].
  - XR16: "stereo files" [B-2]. Bit depth and rate are not stated for the XR16. It shares the manual and app with the XR12, so the same format is likely (inference).
  - MR12: "Files are WAV at 16-bit, 44.1 or 48 kHz, depending on the mixer sample rate" [M-2].
  - Maximum file size, flash drive size and file system: unknown (not in maker text found).
- **Channel count:** 2 (stereo) [B-1].

## 4. Recording settings

- **Sample rate:** 44.1 or 48 kHz [B-1]. "The console operates at 48 kHz by default, but can be changed to 44.1 kHz", on the Setup page's Audio/MIDI tab in the iPad app [B-1]. "Mute the main LR fader before changing clock rates as pops can occur" [B-1].
- **Bit depth:** 16-bit on the XR12 [B-3] and the MR12 [M-2]. XR16: unknown.
- **Recorder source:** selectable ("various sources" [B-1]). The exact menu path and source list: unknown from maker text.
  - Both product pages link a Behringer video, "X AIR How To: USB Recorder (X AIR EDIT) XR12 / XR16" [B-2][B-3]. It was not watched. It is the best lead for the menu path.

## 5. Routing

- The stereo recorder source is chosen in the app ("various sources" [B-1]); the menu path is unknown.
- The manual's Routing section is shared by all four X AIR models. It describes routing "input, output, USB and monitor buses" without saying which models have which groups [B-1 §6.13].
- The XR12 and XR16 have no USB audio interface, so there are no multichannel USB sends to route. This is our inference from section 1; the manual doesn't say it in the routing text.
- Block vs per-slot, and virtual soundcheck playback over USB: n/a. Stereo playback from the flash drive comes back on the stereo USB return channel [B-1].

## 6. Tap points

- These are not relevant to multitrack.
- Which point the stereo recorder taps (for example post-fader main LR): unknown.
- Analog gain and phantom are set per input channel in the app [B-1].

## 7. Gotchas

- **The biggest gotcha: the XR12, XR16 and MR12 look like the XR18 but send no multichannel audio over USB.** You get only a 2-track stereo file on a flash drive.
- They have the same app, the same look and the same "X AIR" family name as the XR18. Users will expect USB multitrack and not get it.
- Workarounds outside USB: use analog direct or aux outs into a separate interface. That is a different product category, and the guide should not promise it.
