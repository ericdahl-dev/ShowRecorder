# Behringer XR18 (and X18) / Midas MR18: multitrack recording facts

- The XR18 and X18 share one manual and one spec table.
- The MR18 is Midas's version of the XR18. Midas's own MR18/MR12 user manual PDF [M-2] confirms 18x18 USB, USB 2.0 type B, and 44.1/48 kHz with 48 kHz default. Its MR18 spec table (§9.1) also lists the supported operating systems: "Windows 7 or higher, Mac OS X 10.6.8 or higher, iOS 7 or higher (iPad), Linux" (checked 2026-11-07). The ManualsLib copy [M-1] agrees on the USB facts. Retailer copies of the spec carry the same OS list [S-1]. midasgroup.com product pages returned nothing on 2026-11-06.
- MR18 facts beyond those in [M-1] and [M-2] are secondary.

Source labels: [B-x] = Behringer (maker). [S-x] = secondary.

## 1. USB audio to a computer

- **Channels:** 18 x 18. "Up to 18 audio channels can be simultaneously recorded, and 18 channels are available for playback" [B-1][B-2].
- **Sample rates:** 44.1 / 48 kHz [B-1][B-2].
- **Bit depth:** USB bit depth is not stated. The converters are "24-bit @ 44.1 / 48 kHz" (A/D CS5368, D/A CS4385) [B-1][B-2]. USB word length: unknown, probably 24-bit.
- **Connector:** "USB 2.0, type B" [B-1][B-2].
- **MIDI:** 16 x 16 on the same USB connection [B-1].
- **MR18:** "the MR18 features an 18x18 USB audio/MIDI interface"; "USB 2.0, type B"; 48 kHz default, 44.1 kHz selectable [M-1][M-2]. Retailer copies agree [S-1][S-2].

## 2. Driver status

- **macOS:** "compatible with CoreAudio on Mac* computers, and to ALSA/Jack on Linux" [B-1]. Spec: "Mac OS X 10.6.8 or higher" and "compatible to CoreAudio on Mac OS X and iOS" [B-1 §9][B-2]. Status: no driver needed (confirmed by maker). ShowRecorder has recorded 18 USB Channels from an XR18 to a Mac (docs/tested-hardware.md).
- **iOS / iPadOS:** "Supported operating systems ... iOS 7 or higher (iPad)" [B-1][B-2]. The manual's hookup drawing "X18 recording with iPad" labels the iPad "iPad with camera connection kit for multi-track recording up to 18 tracks" [B-1 §3.1.1]. **Confirmed by maker for iPad.**
  - iPhone is not named by the maker. **Owner-confirmed [O-2]:** ShowRecorder has recorded all 18 XR18 channels on an iPhone over USB (Eric, 2026-11-06). A full-length show on an iPhone through a powered hub is not tested yet (#327).
- **Windows:** "Windows ASIO driver available as download from behringer.com" [B-1][B-2].
- **Mode switch:** no driver or class-compliant switch. But the USB channel count can be cut to 2x2 in Setup → Audio/MIDI: "The X18/XR18 has an 18x18 channel interface built-in, but sometimes this is overkill for a recording session. For overdubs and simple tracking, the 2x2 interface is more efficient" [B-1 §6.14]. A mixer left at 2x2 sends only 2 channels to the recorder.
- **Sample rate** is set on the same tab: "The console can operate at 48 kHz or 44.1 kHz. Mute the main LR fader before changing clock rates as pops can occur" [B-1].
- **MR18:** Midas's own manual lists the same systems, including "iOS 7 or higher (iPad)" [M-2 §9.1]. Status: confirmed by maker. Distributor copies agree [S-1].

## 3. Recording without a computer

- **XR18 / MR18:** none. The XR18 has no USB Type-A recorder port; the spec table lists only "1 USB Type B" for audio/MIDI [B-1].
- The X18 desk version is the same in the spec table, with no Type A port listed [B-1].
- To multitrack without a laptop, a USB host (iPad or iPhone) is required.

## 4. Recording settings

- **Sample rate:** 44.1 or 48 kHz in Setup → Audio/MIDI tab (X AIR Edit or X AIR app). "The console operates at 48 kHz by default, but can be changed to 44.1 kHz" [B-1]. No word clock input is listed in the spec table, so the clock is internal (inference from the spec table).
- **Channel count:** 18x18 or 2x2, chosen in Setup → Audio/MIDI [B-1 §6.14]. (Corrected 2026-11-06: an earlier version said the count was fixed at 18x18.) The exact control name on that tab is not quoted in the manual: unknown.
- **Bit depth:** not selectable and not stated for USB (see 1).
- **File format:** set by the recording app; the mixer is just the interface.

## 5. Routing

The XR18 **has per-slot USB send selection.**

- **Path:** Routing (the "up/down arrow icon at the top of the Main View screen") → the Inputs/USB grid [B-1].
  - "This allows the specific routing of input, output, USB and monitor buses to be adjusted freely."
  - "Tap inside an empty box in the grid to move the orange dots and reassign the source for input channels, USB channels and P16 monitoring sources."
  - "The USB sends and inputs can be selected from a menu in the folder icon, or they can be moved manually."
  - "Modifications to the Inputs/USB routing can be reset by pressing the revert button" [B-1].
- **Outputs:** "The Routing – Outputs page allows the Main LR, Phones, Aux and P16 sources to be reassigned" [B-1].
- **Default:** "The analog input and USB input channels default to a 1:1 relationship to the channel number, but can be re-routed using the pull-down menus" [B-1 §7.3].
  - This sentence is about each channel's input and USB-return sources.
  - The default USB *send* map (which signal goes to USB 1-18, and at which tap) is not spelled out by the maker: unknown. (An earlier version said "commonly 16 inputs plus aux in 17/18" with no source; that claim is removed.)
  - The hardware chapter says only: "The mixer application allows assignment of channels for recording and playback" [B-1 §2.1].
- **Main mix or buses to USB:** the maker block diagram feeds "MIX 1-6 OUT", "MAIN LR OUT" and "MAIN LR PRE EQ OUT" into the routing patch [B-1 §12.1], so they are patchable signals (see 6). A forum user describes picking the USB recording tap by colored points in X AIR Edit [S-3]. The exact list of non-channel sources offered per USB send in the app: unknown from maker text.
- **Playback (virtual soundcheck):**
  - Per channel: "Click the USB button to route the USB return signal to the selected channel instead of the analog input" (X AIR Edit).
  - In the app: "Use the Mic/USB switch to determine whether the channel is fed by ... USB."
  - "The analog Mic Gain and digital USB Trim can be adjusted independently, though only one source can be used at a time" [B-1].
- **USB 17/18 as monitor source:** "The monitor source defaults to the main LR (post-fader), but you can select a bus, aux, USB 17/18" [B-1].

## 6. Tap points

- **Maker block diagram, X18/XR18** [B-1 §12.1] (corrected 2026-11-06 after reading the diagram itself):
  - Each input channel (CH 1-16) feeds the routing patch at two drawn points: "**PRE LOW CUT OUT**" and "**POST FADER OUT**", plus its insert send. Those are the channel signals the diagram shows as available to outputs and USB sends.
  - "Input / Pre INS / Pre EQ / Pre Fader / Post Fader" is **not** an input-channel list. In the diagram those labels sit on the **Aux Bus 1-6 and Main Stereo** masters (bus taps). An earlier version of this file, and the README table, called them channel taps. That was wrong.
  - "Pre HP / Pre Gate / Post Gate / Pre EQ / Post EQ / Pre Fader / Post Fader / Post Pan" is the tap list for a channel's **aux and FX sends** (mix-bus sends), not for USB.
  - The "Trim (USB Return)" label sits at the channel input, after the A/D.
- **Per USB send:**
  - A review says the "in/out routing page offers ... selectable signal tapping (pre/post fader, pre/post EQ etc) for USB, Aux Outs, Ultranet and Main Outs" [S-4, search snippet only].
  - A forum answer for a "post-EQ/FX, pre-fader" record feed: "Pink, either solid (which includes mutes) or not solid which ignores mutes, just before the fader" (X AIR Edit color-coded tap points) [S-3].
  - **Owner-observed on a real XR18, 2026-11-06** (Eric's mixer, Routing > USB Sends; firmware version not recorded) [O-1]: each USB Send 1-18 has its own **Signal Source** (for example Ch 1) and its own **Signal Tap**. The tap options, in order: Analog, Analog +M, Input, Input +M, Pre EQ, Pre EQ +M, Post EQ, Post EQ +M, Pre Fader, Pre Fader +M, Post Fader. "+M" means the send follows the channel mute (matching the forum's "solid (which includes mutes)" [S-3]).
    - On that mixer USB Sends 1-13 were sourced from Ch 1-13, with Send 1 at the Analog tap. That is one mixer's setting, not a documented factory default.
  - The maker's V1.0 manual does not describe the per-send tap: its diagram shows only pre-low-cut and post-fader channel feeds to the patch, so the list above comes from later firmware (inference).
  - Per channel or global: per USB send [O-1].
- **Analog gain vs digital trim:**
  - Analog headamp gain is "-12...+60 dB, 0.5 dB/step", with switchable +48 V phantom per input [B-1 block diagram].
  - Both sit before every tap.
  - Low cut (HPF), gate, EQ and compressor are in the channel after the "pre low cut" feed [B-1 §12.1]. A pre-low-cut USB send keeps rumble; a post-fader send follows the fader and mute.
  - The digital "USB Trim" applies only to the USB *return* into a channel [B-1].
- **Shared stage box / monitor engineer:** the XR18 has no AES50 or stage-box sharing, so this does not apply. Any app user who changes a channel's gain changes the recorded level.

## 7. Gotchas

- **The iPad is listed by the maker, the iPhone is not.** The spec shows "iOS 7 or higher (iPad)". ShowRecorder has recorded all 18 channels on an iPhone [O-2].
- **The mixer has its own mains power** ("Internal power supply, autorange 100-240 V ... 30 W") [B-2]. It does not need power from the phone. iPhone hub or adapter needs: unknown.
- **The connector is USB-B,** so a USB-C phone needs a USB-C to USB-B cable. A Lightning phone needs a camera-adapter style connection (inference).
- **Changing the sample rate can pop.** Mute the main LR first [B-1].
- **The XR12/XR16/MR12 look similar but have no USB audio interface** (see xr12-xr16-mr12.md).

## Gaps

Leave these out of the guide, or label them plainly:
- **iPhone:** Behringer names the iPad only. ShowRecorder has recorded all 18 channels on an iPhone [O-2]; say that, and say a full-length show through a powered hub is not tested yet (#327).
- **MR18 on iPad/iOS:** closed 2026-11-07. Midas's own PDF lists iOS 7 or higher (iPad) [M-2].
- **Default USB send map** (what USB 1-18 carry out of the box): unknown. Tell readers to check the Routing page.
- **USB bit depth:** not stated (converters are 24-bit).
- **Name of the 18x18 / 2x2 control** on Setup → Audio/MIDI: not quoted. Say "set the USB interface to 18x18".
- **Power for an iPhone or iPad:** the mixer doesn't power the phone; hub or adapter needs are untested.
- **Onboard recording:** none on XR18/X18/MR18, no gap.
